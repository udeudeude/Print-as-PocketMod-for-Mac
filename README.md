# Print as PocketMod for Mac

A native macOS PDF Service that adds **Print as PocketMod** to the PDF menu in the system Print dialog.

It takes the PDF generated by macOS printing, rearranges each group of eight pages into standard PocketMod imposition, and opens the imposed PDF for inspection or printing.

## What it does

For source pages 1 through 8, the landscape sheet is arranged as:

```text
┌──────┬──────┬──────┬──────┐
│  1↓  │  8↓  │  7↓  │  6↓  │
├──────┼──────┼──────┼──────┤
│  2↑  │  3↑  │  4↑  │  5↑  │
└──────┴──────┴──────┴──────┘
```

The top four panels are rotated 180 degrees. Documents longer than eight pages become multiple PocketMod sheets. Incomplete final groups are padded with blank panels.

## Requirements

- macOS 13 or later

## Install

### Easiest: prebuilt release

Download the latest release ZIP from GitHub, unzip it, and double-click `Install.command`. The prebuilt helper app is universal and supports both Intel and Apple Silicon Macs.

Because the current release is not Apple-notarized, macOS may require **right-click -> Open** the first time.

### From source

If you have Xcode Command Line Tools installed:

```sh
git clone https://github.com/udeudeude/Print-as-PocketMod-for-Mac.git
cd Print-as-PocketMod-for-Mac
./scripts/install.sh
```

The installer builds a small native helper app at:

```text
~/Applications/Print as PocketMod.app
```

and installs a PDF workflow item at:

```text
~/Library/PDF Services/Print as PocketMod
```

## Use

1. Open any printable document.
2. Choose **File -> Print**.
3. Open the **PDF** menu at the bottom of the print dialog.
4. Choose **Print as PocketMod** for a clean sheet, or **Print as PocketMod with Guides** for dashed fold lines plus the center cut line.
5. The imposed PDF opens in Preview.
6. Inspect it, then print it at 100% / Actual Size unless your printer requires otherwise.

The generated PDF is temporary and is removed automatically after the viewer has had time to open it. It becomes permanent only if you explicitly save it from the viewer. Stale temporary files left by a crash are cleaned up automatically on a later run.

The source paper size is preserved but forced to landscape orientation, so Letter input becomes Letter landscape and A4 input becomes A4 landscape.

## Why there is a helper app

macOS PDF workflow items are still supported, but on current macOS the process that executes items in `~/Library/PDF Services` is sandboxed. Doing PDF processing directly inside that process can fail silently, especially when the original print job comes from a sandboxed application.

The installed PDF Service therefore does one thing: hand the spool PDF to a normal native application through LaunchServices. The helper app performs the PDF imposition outside that restricted workflow process.

## Development

```sh
swift build
swift test
```

The implementation uses only Apple frameworks: AppKit, PDFKit, Foundation, and Core Graphics. There are no third-party runtime dependencies.

## Uninstall

```sh
./scripts/uninstall.sh
```

## Status

Current implementation includes:

- clean PocketMod output
- optional fold/cut guide output as a second Print-menu command
- mixed portrait/landscape handling, including odd-page landscape correction
- oversized square-page handling recovered from the print spool without reading the original Desktop/Documents file
- multiple PocketMod sheets for documents longer than eight pages
- automatic cleanup of temporary output
- a prebuilt release ZIP with double-clickable install/uninstall commands

The prebuilt app is ad-hoc signed but not Apple-notarized. Developer ID signing and notarization are the main remaining distribution improvements.
