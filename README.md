# Print as PocketMod for Mac

A native macOS PDF Service that adds **Print as PocketMod** to the PDF menu in the system Print dialog.

It takes the PDF generated by macOS printing, rearranges each group of eight pages into standard PocketMod imposition, and opens the imposed PDF in Preview.

## Compatibility

- **macOS 13 or later**
- **Intel Macs**
- **Apple Silicon Macs** (M1 and later)

Release builds are universal binaries containing both Intel and Apple Silicon code. Automated builds and tests run on current GitHub macOS runners, but the project has not been manually tested on every Mac model or macOS release.

## Install

### Downloadable release

**[Download the latest release](https://github.com/udeudeude/Print-as-PocketMod-for-Mac/releases/latest)**

1. Download the release ZIP and unzip it.
2. Open **START HERE.html**.
3. Double-click **Install Print as PocketMod.command**.
4. If macOS says it cannot verify the developer, Control-click or right-click the installer, choose **Open**, then choose **Open** again.
5. Wait for the **Installation complete** message.

No administrator password is required. The installer changes only your user account.

### From source

If you have Xcode Command Line Tools installed:

```sh
git clone https://github.com/udeudeude/Print-as-PocketMod-for-Mac.git
cd Print-as-PocketMod-for-Mac
./scripts/install.sh
```

## Use

1. Open any printable document.
2. Choose **File → Print**.
3. Open the **PDF** menu in the Print dialog.
4. Choose **Print as PocketMod** for a clean sheet, or **Print as PocketMod with Guides** for fold lines plus the center cut line.
5. The imposed PDF opens in Preview.
6. Inspect it, then print it at 100% / Actual Size unless your printer requires otherwise.

The generated PDF is temporary and is removed automatically after Preview has had time to open it. It becomes permanent only if you explicitly save it.

## PocketMod layout

For source pages 1 through 8:

```text
┌──────┬──────┬──────┬──────┐
│  1↓  │  8↓  │  7↓  │  6↓  │
├──────┼──────┼──────┼──────┤
│  2↑  │  3↑  │  4↑  │  5↑  │
└──────┴──────┴──────┴──────┘
```

Documents longer than eight pages become multiple PocketMod sheets. Incomplete final groups are padded with blank panels.

## What gets installed

```text
~/Applications/Print as PocketMod.app
~/Library/PDF Services/Print as PocketMod
~/Library/PDF Services/Print as PocketMod with Guides
```

There is no always-running background service and no network access. The helper runs only when you choose one of the PocketMod items from the Print dialog.

The PDF Service first copies macOS's short-lived print spool into its own temporary staging area, then hands that stable PDF to the helper app. This avoids requesting access to the original Desktop/Documents file.

## Uninstall

From the downloadable release, double-click **Uninstall Print as PocketMod.command**.

From a source checkout:

```sh
./scripts/uninstall.sh
```

## Gatekeeper

The downloadable app is ad-hoc signed, but it is **not Apple-notarized** because the project does not use a paid Apple Developer account. macOS may therefore require the manual Control-click/right-click → **Open** approval step for the installer.

Once the user has explicitly approved and run the installer, it removes quarantine only from the helper copy it installs so macOS does not ask for a second approval when the Print service launches it.

## Development

```sh
swift test -Xswiftc -warnings-as-errors
swift build -c release --product PocketModApp -Xswiftc -warnings-as-errors
```

The implementation uses only Apple frameworks: AppKit, PDFKit, Foundation, and Core Graphics. There are no third-party runtime dependencies.
