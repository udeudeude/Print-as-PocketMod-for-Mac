# Print as PocketMod for Mac

A native macOS PDF Service that adds **Print as PocketMod** to the PDF menu in the system Print dialog.

It takes the PDF generated by macOS printing, rearranges each group of eight pages into standard PocketMod imposition, and opens the imposed PDF for inspection or printing.

## What it does

For source pages 1 through 8, the landscape sheet is arranged as:

```text
┌──────┬──────┬──────┬──────┐
│  1↓  │  8↓  │  7↓  │  6↓  │
├──────┼──────┼──────┼──────┤
│  2↑  │  3↑  │  4↑  │  5↑  │
└──────┴──────┴──────┴──────┘
```

The top four panels are rotated 180 degrees. Documents longer than eight pages become multiple PocketMod sheets. Incomplete final groups are padded with blank panels.

## Requirements

- macOS 13 or later
- Xcode Command Line Tools, which provide `swift`

Check with:

```sh
swift --version
```

## Install

Clone the repository, then run:

```sh
./scripts/install.sh
```

The installer builds a small native helper app at:

```text
~/Applications/Print as PocketMod.app
```

and installs a PDF workflow item at:

```text
~/Library/PDF Services/Print as PocketMod
```

## Use

1. Open any printable document.
2. Choose **File -> Print**.
3. Open the **PDF** menu at the bottom of the print dialog.
4. Choose **Print as PocketMod**.
5. The imposed PDF opens in your default PDF viewer.
6. Inspect it, then print it at 100% / Actual Size unless your printer requires otherwise.

The source paper size is preserved but forced to landscape orientation, so Letter input becomes Letter landscape and A4 input becomes A4 landscape.

## Why there is a helper app

macOS PDF workflow items are still supported, but on current macOS the process that executes items in `~/Library/PDF Services` is sandboxed. Doing PDF processing directly inside that process can fail silently, especially when the original print job comes from a sandboxed application.

The installed PDF Service therefore does one thing: hand the spool PDF to a normal native application through LaunchServices. The helper app performs the PDF imposition outside that restricted workflow process.

## Development

```sh
swift build
swift test
```

The implementation uses only Apple frameworks: AppKit, PDFKit, Foundation, Uniform Type Identifiers, and Core Graphics. There are no third-party runtime dependencies.

## Uninstall

```sh
./scripts/uninstall.sh
```
